# Lurkwire brand assets

Vector sources (Inter ExtraBold wordmark is outlined; no font dependency):

- `lurkwire-icon.svg` — transparent app mark, used in the tab strip, new tab, and About
- `lurkwire-icon-dark-bg.svg` — rounded app icon on `#0f0a1a`, used for Linux/Windows/macOS packaging
- `lurkwire-wordmark-light.svg` / `lurkwire-wordmark-dark.svg` — wordmark for dark and light chrome

`png/` holds official 512/1024 rasters. Packaged icons in `apps/desktop/build/` (`icon.png`, `icon.svg`, `icon.ico`, `icon.icns`, and `icons/{size}x{size}.png`) are generated from the dark-background master.
